# Situation Report page redesign

## Build
- Replace the blank home page with a complete Situation Reporting workspace using the supplied page structure and report fields.
- Reorganize the page into a compact command header, event selector and context strip, centered official report, and saved snapshot register.
- Preserve every supplied action and generation form field while redesigning only their placement and presentation.

## Visual system
- Use the chosen Command Navy palette with the browser’s default system font.
- Follow a restrained Microsoft-style language: flat surfaces, thin borders, 4–8px corners, clear focus states, and minimal shadows.
- Reduce instructional copy and emphasize labels, values, section titles, tables, and report status.

## Responsive behavior
- Keep the document-first hierarchy on desktop.
- Stack event details, report metadata, and modal fields cleanly on narrower screens without losing data or actions.

## Validation
- Verify the page visually at desktop and mobile sizes.
- Test the event selector, action menu, saved report rows, and generate dialog.
- Confirm the preview builds without errors and includes page-specific metadata.
